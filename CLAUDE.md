# Claude Code Instructions

Before working in this repository, read and follow the root `AGENTS.md`.

Packages are deep modules: see [src/packages/README.md](./src/packages/README.md) before adding or importing one.

Before working in a subdirectory, also read and follow any `AGENTS.md` files along the path from the repository root to that directory. Each nested `AGENTS.md` applies to its directory and descendants; when instructions conflict, the more specific file takes precedence within its scope.
