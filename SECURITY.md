# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately through a
[private security advisory](https://github.com/danilomartinelli/vibecoding-starter-js/security/advisories/new).

We aim to respond within 7 days. Please include:

- Affected commit
- Steps to reproduce
- Impact description

## Supported versions

This project has no releases. Only the latest commit on `master` receives fixes.

## Disclosure

We appreciate responsible disclosure. Once a fix is merged, we will
acknowledge the reporter in the advisory (unless anonymity is requested).
